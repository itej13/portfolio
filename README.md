# Tejas Das Portfolio

A minimal, dark-mode-first developer portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npx vercel --prod
```

Vercel auto-detects Next.js. If deploying from Git, import the repository in the Vercel dashboard and use the default build settings.
